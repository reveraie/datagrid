Features

Section titled “Features”

High Performance

Built from the ground up for speed. Handles thousands of rows with ease using row virtualization and on-demand loading.

Zero Dependency

No third-party libraries (besides React). Drop it into any project without worrying about bloat or conflicts.

Fully Customizable

Use custom components to render cells and editors. Tailor the look, feel, and behavior to match your application’s needs.

Rich Interaction

Includes essential features like column resizing, reordering, and in-cell editing right out-of-the-box.

Data Grouping

Organize and group related rows to provide a clear and structured view of your data.

Lightweight & Simple

With a minimal API and a focus on core grid functionality, it’s easy to learn, use, and extend.
