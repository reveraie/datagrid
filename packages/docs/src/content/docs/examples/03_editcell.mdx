This example allows the user to edit the content of the **Subject** column. The custom rendering is achieved by providing a render function in the `DataGridColumn` object. This function takes the value of the cell as an argument and returns the JSX to be rendered.

```ts
  const columns: DataGridColumn[] = [
    //...
    {
      name: "subject",
      label: "Subject",
      width: "*",
      render: (value) => {
        return (
          <SubjectEditor value={value as string} onChange={handleSubjectEdit} />
        );
      },
    },
    //...
  ];
```
