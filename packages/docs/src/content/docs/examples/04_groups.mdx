The `DataGrid` supports group rows provided via the DataGridRow object:


```ts
const rows: DataGridRow[] = [
    // this row will appear as a group row
    {
      type: "group",
      values: {
        Since: "Today",
      },
    },
    // we do not need to privide the type for standard rows
    {
      values: {
        status: true,
        from: "Bob Wilson",
        favorite: true,
        subject: "Important announcement",
        attachments: 3,
        date: "2023-01-01",
      },
    },
    ///...
  ]
```
